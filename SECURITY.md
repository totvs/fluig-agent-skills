# Security Policy

O projeto fluig-agent-skills tem como objetivo fornecer Agent Skills seguras, transparentes e alinhadas às boas práticas de desenvolvimento da plataforma Fluig.

## Princípios

- Todas as skills são compostas por arquivos de texto e podem ser auditadas.
- As skills utilizam apenas APIs públicas e recursos suportados da plataforma Fluig.
- Sempre que aplicável, as skills incentivam boas práticas de segurança, como validação de entradas, sanitização de conteúdo e prevenção de vulnerabilidades comuns.

## Reportando um problema

Caso identifique uma vulnerabilidade, instrução insegura ou comportamento inesperado em uma skill, entre em contato com os mantenedores do projeto para que o problema possa ser analisado e corrigido.
