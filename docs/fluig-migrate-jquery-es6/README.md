# Exemplos de Uso — fluig-migrate-jquery-es6

Prompts prontos para acionar a skill `fluig-migrate-jquery-es6` com um agente de IA, em três níveis de complexidade.

## Simples

> Migre este trecho de código jQuery para JavaScript ES6+.

## Intermediário

> Migre o arquivo jQuery deste widget `SuperWidget` para ES6+, trocando os seletores e os `.on('click')` por `document.querySelector` e `addEventListener`, sem alterar o comportamento.

## Completo

> Vou colar o arquivo legado em jQuery de um Custom Element para você modernizar para ES6+. Converta `$.ajax` para endpoints internos em `FLUIGC.ajax`, troque `var` por `const`/`let`, substitua `.each()` por `for...of` e as concatenações de string por template literals, preservando o comportamento observável e mantendo a i18n existente via `${i18n.getTranslation('chave')}`. Garanta que nenhum novo uso de jQuery seja introduzido.
