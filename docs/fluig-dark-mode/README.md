# Exemplos de Uso — fluig-dark-mode

Prompts prontos para acionar a skill `fluig-dark-mode` com um agente de IA, em três níveis de complexidade.

## Simples

> Adapte este CSS ao modo escuro.

## Intermediário

> Vou colar o CSS de um cabeçalho de widget com cores hexadecimais fixas. Substitua-as por variáveis de tema no formato `var(--fs-color-*)` para que o componente acompanhe a troca de tema.

## Completo

> Segue o arquivo CSS de um card com `color`, `background-color` e `box-shadow` em valores fixos (`#202020`, `#ffffff`, `rgba(...)`) que fica ilegível no modo escuro. Adapte-o ao dark mode trocando cada cor pela família de token adequada ao seu papel (neutros para texto/fundo, ação ou marca conforme o caso) usando `var(--fs-color-*)`, substitua as sombras por tokens `--fs-shadow-*` e use apenas variáveis documentadas no Style Guide. Preserve o layout e o comportamento, mudando somente a origem da cor.
